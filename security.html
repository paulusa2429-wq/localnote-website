SECURITY REVIEW

Security review, in one page.

Everything on this page can be checked from the machine itself: the connection log, the audit pack, airplane mode. If your review process needs a call anyway, the founder answers it — but it shouldn’t need one.

DATA FLOW

Where the data goes — and doesn’t.

A meeting is recorded by the app on this computer. Transcription and all AI processing run on this computer, using models downloaded once during setup. Transcripts, summaries, ledgers and documents are stored on this computer. The app makes no connection during core work; every connection it ever makes — model downloads at setup, update checks, and the optional counts-only usage beacons (off by default) — is recorded in a connection log on the machine, by day, host and category, and that log is exportable as part of the audit pack. Nothing is uploaded for processing, because there is nothing to upload to: LocalNote operates no server that receives customer data. Files leave the machine only when the user exports or sends them.

MODEL PROVENANCE

The models, and where they come from.

Speech and language models are open-weight models downloaded once at setup (~4.8 GB total) from their public repositories, then used entirely on-device. After setup, the core product needs no network access — run it in airplane mode and check the connection log; the silence is the evidence.

ENCRYPTION POSTURE

Encryption, stated exactly as it is.

The consent log is encrypted and hash-chained. Recordings, transcripts and the app’s database are not separately encrypted by LocalNote — protect them with your operating system’s full-disk encryption (FileVault / BitLocker), the same control you apply to any sensitive local file. We state this plainly because a security review should never have to discover it.

MCP & INTEGRATIONS

Connected tools, on a short leash.

The local MCP server is off by default. When a user switches it on, each AI client is approved individually, scoped to selected meetings, denied by default beyond that scope, and every access is written to an audit log. Local is not the same as offline: a connected client is a deliberate, logged exception the user grants — never a background behaviour.

CONSENT & RECORDING

Recording is user-started, never ambient.

Recording is user-started, in-app, with a consent reminder and an encrypted consent log entry. LocalNote does not join calls as a bot and does not record in the background. Obtaining consent where the law requires it remains the user’s responsibility — the app’s job is to make the consent it records provable.
