THE WHOLE PRODUCT · ONE TREE

Every feature. One tree.

The story page tells this week as prose. This page draws it: one fictional sample week — the same Acme renewal, with Maya Chen and Dana Park — as a tree of connected nodes. The trunk is the week; each branch is a day; each scene hands its work to the next along the labelled line between them. Every feature in the current pre-release build is a leaf, exactly once, on the scene where the week fires it — 72 in all, so nothing can hide.

Every name, number and line on this page is fictional — it is the app's own sample data. The week is invented; the features are not: each one is in the current pre-release build of LocalNote.
